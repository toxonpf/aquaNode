# Observation map retired

The map was removed from the public website on 15 November 2026. The owner
clarified that no buoys have been shipped to partners or deployed abroad.
The latest development milestone is the second buoy version with OCA.

Source history and obsolete map tests are preserved in
[archive/observation-map](../archive/observation-map/README.md). The original
station CSV is unchanged. The map and its generated location examples are no
longer bundled or linked. Old /map URLs redirect to /journal#oca-v2.

Earlier prototype work, sensor measurements, the GEEP award and the dated
R0.3/revC engineering records remain published. No date has been invented for
the OCA collaboration milestone.
