# Профиль для ларпа

`larp.config.json` описывает сценарий, где pH, EC, температура и USB работают прекрасно. Он содержит готовые статусы и пример показаний для макета интерфейса или презентации. Входная точка — `presentation.config.json` в корне проекта.

Значения в `sample` вымышленные, режим `simulation`. Прошивка не загружает этот профиль; реальные отчёты и коэффициенты калибровки сохранены отдельно. Это позволяет показывать работающий сценарий в демо без подмены истории инженерных проверок.
