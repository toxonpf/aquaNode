# Подключения EC + pH revC

Работы с проводкой проводить при отключённых USB, аккумуляторе и внешнем источнике. Контакты датчиков и DFR0504 определять по надписям **MCU / SEN / − / + / A**, а не по цвету кабеля. Номера M3/M4 в CAD логические; они не обозначают порядок контактов на фотографии производителя.

## pH — активный изолированный канал

| Откуда | Куда | Примечание |
|---|---|---|
| pH-электрод из SEN0169-V2 | BNC платы SEN0169-V2 (M3) | Голый электрод напрямую к ADS1115 не подключать |
| M3 − | DFR0504 (M4) **SEN −** | PH_ISO_GND, изолированная земля |
| M3 + | M4 **SEN +** | Изолированное питание около 5 В |
| M3 A | M4 **SEN A** | Вход сигнала изолированной стороны |
| M4 **MCU −** | J9.1 / GND | Общая земля AquaNode |
| M4 **MCU A** | J9.3 / PH_OUT | Сигнал после развязки |
| M4 **MCU +** | PS1 + | Отдельный источник 5,00 ±0,10 В, ≥0,5 А |
| PS1 − | GND / TP6 | Общая земля только стороны MCU |
| J9.2 / PH_SUPPLY | **Нет контакта в кабеле** | Вынуть и изолировать; не подавать сюда внешние 5 В |
| JP1 | **Шунт снят** | Не ставить 1–2 или 2–3 в этой сборке |
| J9.3 | R9 49,9 кОм → PH_DIV | Штатная цепь платы |
| PH_DIV | R10 49,9 кОм → GND | Делитель примерно 1:2, оба резистора 0,1% |
| PH_DIV | R15 1 кОм → ADC_PH → U1.4 / AIN0 | C11 на PH_DIV, C13 на ADC_PH; оба к GND |

Никаких других соединений с PH_ISO_GND/PH_ISO_5V/PH_ISO_OUT. Не замыкать изоляцию экраном, крепежом или землёй обычного осциллографа. Проверить электрическую изоляцию погружённой оболочки температурного щупа от его проводов. DFR0504 является развязкой измерительной цепи, не барьером для подключения сетевого напряжения.

Включение: сначала AquaNode/ADS1115 от штатного USB/батареи, затем внешний источник M4. Выключение: сначала внешний источник M4, дождаться спада PH_OUT/ADC_PH, затем AquaNode. Питание M4 при выключенном ADS1115 может подпитывать 3V3 через аналоговый вход; номинальный делитель этого не предотвращает. Порядок ручной, автоматическая блокировка не реализована.

## EC и температура

| Откуда | Куда | Примечание |
|---|---|---|
| SEN0244 + | TP5 / 5V_PH отдельным W1 | Прежний boost/LDO включается GPIO2 HIGH |
| SEN0244 − | J7.1 / GND | Общая земля |
| SEN0244 A | R21 1 кОм → J7.3 / EC_FILTERED | Внешний R21 |
| J7.3 | Штатный R4 100 Ом → EC_ADC / J1.1 / GPIO1 | C19 100 нФ от EC_ADC к GND, после R4 |
| J7.2 | **Нет контакта в кабеле** | На плате здесь 3V3; не соединять с 5 В |
| R3 | **DNP / снять** | Подтяжка искажает EC |
| DS18B20 VDD | TP3 / 3V3 | Внешнее трёхпроводное питание |
| DS18B20 GND | TP6 / GND | Не PH_ISO_GND |
| DS18B20 DQ | R20 100 Ом → DS_LOCAL / J1.7 / GPIO43 | GPIO43 не использовать как UART TX |
| R19 4,7 кОм | DS_LOCAL ↔ 3V3 | Подтяжка 1-Wire |
| D3 | DS_CABLE ↔ GND | ESD-диод на стороне щупа до R20 |

## Контроллер, ADS1115 и питание

| Контакт | Сигнал / назначение |
|---|---|
| J1.1 / D0 / GPIO1 | EC ADC |
| J1.2 / D1 / GPIO2 | PH_EN — историческое имя; в revC включает питание **EC**, pH имеет отдельный источник |
| J1.3 / D2 / GPIO3 | Не подключён |
| J1.4 / D3 / GPIO4 | BAT_EN; LOW в стендовой прошивке |
| J1.5 / D4 / GPIO5 | I²C SDA → U1.9; подтяжка к 3V3 |
| J1.6 / D5 / GPIO6 | I²C SCL → U1.10; подтяжка к 3V3 |
| U1.1 ADDR / U1.3 GND | GND; адрес 0x48 |
| U1.2 ALERT/RDY | Не подключён; готовность опрашивается по I²C |
| U1.4 AIN0 | ADC_PH |
| U1.5 AIN1 | ADC_BAT; канал в прошивке не считывается |
| U1.6 AIN2 / U1.7 AIN3 | GND; EC сюда не подключать |
| U1.8 VDD | 3V3 |
| J3 | Защищённый аккумулятор 1S, полярность фактического кабеля проверить |
| J4 | Только к нижним BAT+/BAT− площадкам XIAO |
| J5 | Двухпроводный выключатель батареи; USB отключается отдельно |
| Wio SX1262 | Штатное B2B; D0–D5 не перемыкать на гребёнку Wio |

Внешние 5 В PS1 не подавать на TP5, BOOST_RAW, 3V3, XIAO 5V/VBUS или BAT. Контакты правой гребёнки нумеруются по CAD; не определять их по зеркальному изображению платы.
