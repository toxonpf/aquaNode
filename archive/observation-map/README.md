# Retired observation map

Removed from the published website on 15 November 2026 at the owner's request.
The owner clarified that no AquaNode buoys have been shipped to partners or
deployed abroad. The latest development milestone is creation of the second
buoy version with OCA specialists. Earlier prototypes, measurements, award and
engineering records remain part of the active website.

This directory preserves the previous map implementation and its tests for
source history. It is outside Vite's entry imports and the active Playwright
test directory. Imports retain their former source layout; this is a reference
snapshot, not a standalone application. The original station CSV remains at
the repository root, unchanged.

The old deployment descriptions, approximate marker counts and generated buoy
readings in this snapshot are superseded. They are not evidence of real buoy
installations, shipments or field measurements. The previous documentation is
retained as `previous-observation-map.md` with the same superseded status.

Old `/map` URLs redirect to `/journal#oca-v2`; no map is served there.
