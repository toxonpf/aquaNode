# AquaNode R0.3-EC-revB
Инженерный пакет от 29.10.2026. Основа: AquaNode_R0.3_EC, исходная R0.3 не изменена. Не R0.4; SHT40 отсутствует.

**Статус: проект для ревью и стенда. Изготовление по этому пакету пока не разрешено техническим выпуском. Работа устройства в воде не подтверждена.**

Цель AquaNode — доступный учебный буй для мониторинга пресной воды, который школьники смогут собирать и использовать для изучения окружающей среды. Эта ревизия готовит экспериментальную оценку EC на TDS-модуле SEN0244. Она не измеряет конкретную соль, не предназначена для моря и не определяет безопасность питьевой воды.

## Главные изменения
SEN0244 питается от существующего TP5 / 5V_PH через отдельный изолированный провод. Кабельный контакт J7.2 удалить и изолировать: на плате там остаётся 3V3. R3 обязателен DNP. C19 перенесён на сторону EC_ADC / J1.1 после R4. DS18B20 остаётся на D6/GPIO43. Прошивка включает общий узел 5 В через GPIO2, поэтому pH-модуль на этом стенде физически отключён, его электрод вынут из воды. Попытка подключить 5 В к J7.2 повредит 3V3-систему.

Стоимость всего буя неизвестна. Проверенная цена SEN0244 — $11.80; ориентир доплаты за EC $13.80–16.80 и $23.80–36.80 со стандартами является плановым, без доставки и налогов. Он предполагает уже собранный базовый узел boost/LDO.
