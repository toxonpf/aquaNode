# Стендовая прошивка revB
ec_bench — только EC ADC + DS18B20 + USB JSONL. Нет измерения pH/батареи, радио, mesh, облачного клиента и deep sleep. Не скомпилирована в этой среде.

Цель: XIAO ESP32S3, Arduino ESP32, USB CDC on boot enabled. OneWire и DallasTemperature. Используется GPIO1 ADC1, GPIO43 1-Wire, GPIO2 общий boost/LDO, GPIO4 BAT_EN=LOW. Serial — USB, не UART0. Скетч включает 5V_PH после настройки; оператор до включения обязан проверить жгут, отключить J9 и убрать pH-электрод.

Начальная пауза 60 секунд — удобство стенда, не подтверждённое время стабилизации. После неё идут реальные ADC/температурные значения. EC=null до SUPPLY_VALIDATED=true, CALIBRATED=true и корректной калибровки. SUPPLY_VALIDATED — ручная отметка прохождения стенда, НЕ датчик питания и не динамическая защита. При смене сборки/источника сбросить её. TEMPERATURE_VALIDATED=false ограничивает выдачу EC температурой 25±0,5 °C. Не включать этот флаг до температурных тестов.

Схема JSONL: aquanode.ec.revB.v1; ec_mv, adc_spread_mv, temperature_c, ec25_estimated_us_cm (null при недопуске), ec_status, calibration_id, boot_id, seq, uptime_ms. physical_validation=false отражает статус этой поставки; после реальных испытаний нужен отдельный контролируемый релиз. estimated не означает независимую валидацию.

Сборка: repro/build_firmware.ps1. Скрипт не устанавливает зависимости автоматически и не выдаёт отсутствие инструмента за успех. Зафиксировать версии core/libraries и полный лог. calibration.h по умолчанию содержит NAN, а не тестовые коэффициенты. Для генерации нового заголовка из реального JSON использовать test_tools/export_calibration.py; не редактировать коэффициенты по памяти. После изменения заголовка повторно собрать прошивку и сохранить его SHA256 рядом с журналом испытания.
