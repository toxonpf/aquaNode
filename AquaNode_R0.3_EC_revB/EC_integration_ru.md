# Сборка revB: единственная текущая инструкция
Все работы с проводкой — при отключённых USB и аккумуляторе. Это внешняя стендовая сборка на изолированной макетной плате; R19/R20/R21/C19/D3 не размещены на несущей PCB. Референсы M1/M2 — логические контакты; цвета проводов и типы разъёмов проверить прозвонкой.

| Соединение | Действие |
|---|---|
| R3 на несущей плате | Не устанавливать / снять. Подтяжка искажает EC. |
| SEN0244 VCC (+) | Отдельный провод W1 от TP5 / 5V_PH; не от J7.2. |
| J7.2 | На PCB остаётся 3V3. Кабельный контакт вынуть, изолировать; не соединять с W1. |
| SEN0244 GND (-) | J7.1 / GND. |
| SEN0244 A | R21 1 кОм → J7.3 / EC_FILTERED → штатный R4 100 Ом → EC_ADC / J1.1 / GPIO1. |
| C19 100 нФ | EC_ADC / J1.1 к GND, максимально близко к контакту MCU, после R4. |
| DS18B20 VDD | TP3 / 3V3, внешнее питание; не паразитное. |
| DS18B20 GND | TP6 / GND. |
| DS18B20 DQ | Через R20 100 Ом к J1.7 / D6 / GPIO43 (DS_LOCAL). |
| R19 4,7 кОм | Между DS_LOCAL и 3V3. |
| D3 PESD3V3S1BA | Между DS_CABLE (сторона датчика R20) и GND. |
| J9 pH | Полностью отключить для EC-стенда; убрать pH-электрод из образца. |
| JP1 | Для стенда pH не нужен; убрать шунт, хранить отдельно. Не ставить два шунта. |
| Q1/Q2/U7/U8 | Оставить установленными; GPIO2 HIGH включает питание EC через общий boost/LDO. |

Аналоговый провод короткий, ориентир до 100 мм от модуля до MCU; силовые токи boost не пускать по возврату аналогового сигнала. Для C19 выбрать керамику X7R 100 нФ ≥10 В, R19/R20/R21 1%, ≥0,125 Вт. Соединения защитить от натяжения и воды. Датчик не питать от отдельного источника при выключенном XIAO: может возникнуть подпитка GPIO через вход. Проверка отключения обязательна даже при общем источнике из-за заряда конденсаторов.

D2/D3 — ESD-защита, не гальваническая развязка, не защита от молнии, не гарантия ограничения до безопасного уровня на любом выбросе. AIN2/AIN3 ADS1115 остаются на GND. Радио подключается штатным B2B; не соединять левую гребёнку Wio с D0–D5.

Перед подключением SEN0244 проверить 5V_PH на нагрузке 1 кОм (около 5 мА) и 820 Ом (около 6,1 мА), затем с датчиком. Проверить BOOST_RAW и 3V3. До тестов разрешены только сборка и осмотр; не считать выбранный способ питания проверенным.
