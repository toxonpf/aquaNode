# Пакет веб-разработчику
Ревизия R0.3-EC-revB, 29 октября 2026. Это готовый контент-пакет, не опубликованный сайт.

Использовать copy_ru.md / copy_en.md как текст, status.json как машинный источник статуса, evidence.md как реестр подтверждений, publishing_rules.md как правила публикации. assets/architecture.svg — единственная разрешённая здесь иллюстрация. Схемы и фотографии производителей не брать за фото нашего устройства.

Показать у проекта заметную подпись «Инженерная разработка — аппаратные испытания предстоят» / “Engineering development — hardware validation pending”. Не превращать null в ноль, estimated в measured accuracy, программный тест в процент готовности продукта. Пока нет реальных данных, не выводить график с правдоподобными значениями.

Структура страницы: краткое описание → зачем школьникам → что подготовлено → что проверяем дальше → открытые материалы/ограничения. CTA «Обсудить стендовые испытания» без выдуманного контакта; контакт и действующую форму добавляет владелец сайта. Не добавлять логотипы MIT, партнёров, награды, фотографии или утверждения о пилоте без отдельных предоставленных подтверждений.
