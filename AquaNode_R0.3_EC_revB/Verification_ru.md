# Реально выполненные проверки revB
Дата: 29.10.2026. Исходная R0.3 и исходная R0.3_EC не изменены: checks/source_preservation.json содержит результат SHA256-сверки.

- 15 Python-тестов синтетической модели: PASS, checks/python_tests.txt. Это не тест исполнения C++ на ESP32.
- 155 контактов схемы сверены с design.json по координатам проводов/меток; pads PCB сверены с design.json, проверен DNP R3: PASS, checks/static_review.json.
- Сегменты/переходы/полигоны, pads и положения footprints совпадают с предыдущей EC-версией. Изменена маркировка, внешние соединения и логика сборки. Это не проверка геометрических зазоров.
- JSON и структуры S-expression читаются; Python исходники разбираются. Разбор не заменяет native ERC/DRC.
- Таблица подключений PDF отрендерена и просмотрена. Она не Schematic.pdf.
- Финальный ZIP проверяется на CRC и по SHA256SUMS.txt при упаковке.

НЕ выполнено: компиляция ESP32, native ERC, native DRC, актуальный полный экспорт схемы и производственный выпуск, аппаратные измерения, радио/mesh, корпус в воде. Причины недоступности программ — checks/environment.txt. Блокирующие инженерные вопросы — engineering/Audit_ru.md.

Старые отчёты в history_ec_revA и baseline_r03 не являются результатами revB.
